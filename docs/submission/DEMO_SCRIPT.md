## 1. 录制口径

- Vela 是面向中国企业法务的拉美投资前合规协查过程保证平台。
- 当前完成端到端验证的首个 Capability Pack：巴西 · 圣保罗州 · 新能源制造 · 绿地设厂。
- 环境许可是当前研究最深入的维度；所有法律内容为 `provisional`。
- 业务负责事实和补件；法务负责法律研究和结论。
- 两个账号使用同一产品、同一前端端口 `5180`，系统按登录角色分流。
- 正式结果来自真实 API；Aurora 是虚构测试案例，不含真实客户数据。
- 律师认证、客户 UAT、客户生产部署和正式 Release 为 `blocked_external`；这不是系统失败。

### 00:25–01:15｜业务账号：事实与补件

**00:35–00:48** 画面：查看“项目材料”中的基础材料，再进入“事实确认”确认或更正一项事实。  
**旁白**：业务查看已接收材料，并按项目实际情况确认或更正事实，不需要处理法律研究字段。

**00:48–00:58** 画面：展示三项“待补充信息”。  
**旁白**：当前待补充三项信息：最终场址或选址状态、危险品最大库存、主要生产设备及活动分类。

**00:58–01:08** 画面：上传或展示 `AURORA_SUPPLEMENT_FACT.txt`，点击“提交法务”。

**01:08–01:15** 画面：停留在“已补充，等待法务复核”。  
**旁白**：状态更新为“已补充，等待法务复核”，业务阶段完成。

### 01:15–01:25｜切换角色

**画面**：退出业务账号，在同一 `http://127.0.0.1:5180` 登录 `legal@demo.vela`。

**旁白**：现在退出业务账号并登录法务账号。无需更换系统或端口；法务登录后直接进入 Aurora 法务工作台。

### 01:25–02:20｜法务工作台前四页

**01:25–01:40 项目总览**：展示虚构案例说明、环境许可研究重点和版本身份。  
**旁白**：项目总览说明当前 Pack 的能力边界。正式结果来自真实 API，而不是前端固定返回。

**01:40–01:53 材料与事实**：展示基础材料、补充材料和业务确认状态。  
**旁白**：材料和业务事实在同一项目下留痕，法务据此复核；未确认信息不会被当作结论。

**01:53–02:07 固定 30 项**：展示 Pack 总数、Scope 内外状态。  
**旁白**：这里的 30 项是 Pack 固定调查分母，也就是 30 个调查清单事项，不是 30 条法律结论。

**02:07–02:20 法律研究**：展示 ResearchItem、来源和 `provisional` 边界。  
**旁白**：法律研究由法务负责。当前法律内容统一标记为 provisional，仍需专业复核。

### 02:20–03:35｜Claim、缺口与 CoverageProof

**02:20–02:48 Claim 与缺口**：展示真实法务草稿与未解决缺口。  
**旁白**：Claim 与缺口分开呈现；系统不会因没有充分事实或证据而补写正式法律意见。业务补件改变的是可核验输入，法务负责研究与结论。

**02:48–03:08 Gate 状态**：展示拒绝或受限状态及原因。  
**旁白**：当事实、法源或外部证据不足时，Gate 会拒绝或限制后续动作。可拒绝是过程保证的一部分，不是错误兜底。

**03:08–03:35 CoverageProof 0.2**：展示 `schema_version=0.2`、`pack_total=30`、Scope 内处置与 out-of-scope 计数。  
**旁白**：CoverageProof 0.2 披露固定分母和处置计数，让缺口不能被隐藏。它证明过程绑定和计数可复核，不证明法律判断一定正确。

### 03:35–04:25｜交付边界与审计

**03:35–03:58 交付中心**：特写 `blocked_external` 以及律师认证、客户 UAT、客户生产部署、正式 Release 四项状态。  
**旁白**：交付中心保持 blocked external，因为律师认证、客户 UAT、客户生产部署和正式 Release 尚需真实外部证据。这个状态是预期安全边界，不是系统失败。

**03:58–04:25 审计记录**：扫过材料上传、事实确认、业务提交、研究、Claim、Proof、Gate 和交付状态事件。  
**旁白**：审计记录把操作者、时间、对象、版本和状态变化串联起来。每一项正式结果来自真实 API，并可回到对应材料与责任角色复核。

### 04:25–04:45｜结尾

**画面**：回到项目总览；屏幕保留“虚构测试案例”“provisional”“blocked_external”三项标识。

**旁白**：  
Vela 不替代律师。它解决的是投资前合规协查过程如何可追溯、可复核、可拒绝和可交付：业务确认事实，法务形成法律研究与结论，系统守住证据和外部批准边界。
