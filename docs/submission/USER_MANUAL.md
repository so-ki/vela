# Vela 产品使用手册

星瀚杯复赛最终提交版 · 2026-07-19  
演示案例：Aurora 储能系统集成工厂（虚构测试案例）

> Vela 是面向中国企业法务的拉美投资前合规协查过程保证平台。当前完成端到端验证的首个 Capability Pack 为“巴西 · 圣保罗州 · 新能源制造 · 绿地设厂”，环境许可是当前研究最深入的维度。

## 1. 产品定位与当前能力边界

Vela 管理材料、事实、调查事项、法律研究、Claim、CoverageProof、Gate、交付状态和审计记录之间的可追溯关系。正式结果来自真实 API，不是前端固定返回；系统不替代律师，也不自动出具正式法律意见。

- 当前法律内容统一为 `provisional`，需由法务复核。
- 当前 Pack 不代表拉美、全巴西或市级规则已完整覆盖，也不承诺实时完整更新。
- 律师认证、客户 UAT、客户生产部署和正式 Release 均为 `blocked_external`。
- Aurora 为虚构测试案例，名称、参数和材料均不含真实客户数据。

## 4. 业务端典型流程（约 4–5 分钟）

业务只负责项目事实与补件，不需要理解 ResearchItem、Claim、CoverageProof、法律研究、法源匹配分数或交付 Gate 的内部结构。

| 步骤 | 操作 | 预计时间 |
|---|---|---:|
| 1 | 登录业务账号，系统进入 Aurora 项目材料与补件中心 | 30 秒 |
| 2 | 在“项目材料”查看 `AURORA_BASE_MATERIAL.txt` | 30 秒 |
| 3 | 在“事实确认”确认或更正一项业务事实 | 45 秒 |
| 4 | 查看三项待补充信息：最终场址或选址状态、危险品最大库存、主要生产设备及活动分类 | 45 秒 |
| 5 | 上传 `AURORA_SUPPLEMENT_FACT.txt` | 45 秒 |
| 6 | 点击“提交法务” | 20 秒 |
| 7 | 核对状态“已补充，等待法务复核” | 20 秒 |

完整顺序：  
`登录业务账号 → 进入 Aurora 项目材料与补件中心 → 查看项目材料 → 确认或更正业务事实 → 查看待补充信息 → 上传补充材料 → 提交法务 → 查看“已补充，等待法务复核”状态`

## 5. 法务端典型流程（约 6–8 分钟）

法务负责法律研究和结论。法律内容在当前阶段均为 `provisional`。

| 步骤 | 操作 | 预计时间 |
|---|---|---:|
| 1 | 退出业务账号，登录法务账号；系统直接进入 Aurora 法务工作台 | 45 秒 |
| 2 | 项目总览：确认虚构案例、真实 API 与版本身份 | 40 秒 |
| 3 | 材料与事实：核对业务补件及确认状态 | 45 秒 |
| 4 | 固定 30 项：核对 Pack 固定调查分母 | 40 秒 |
| 5 | 法律研究：查看 ResearchItem 与来源边界 | 50 秒 |
| 6 | Claim 与缺口：查看法务草稿、缺口和 `provisional` 状态 | 50 秒 |
| 7 | CoverageProof：核对 0.2、Pack 分母与处置计数 | 50 秒 |
| 8 | 交付中心：核对 `blocked_external`，不是系统失败 | 40 秒 |
| 9 | 审计记录：核对操作、状态、版本与时间线 | 40 秒 |

完整顺序：  
`登录法务账号 → 直接进入 Aurora 法务工作台 → 项目总览 → 材料与事实 → 固定 30 项 → 法律研究 → Claim 与缺口 → CoverageProof → 交付中心 → 审计记录`

“固定 30 项”仅指 Pack 固定调查分母或 30 个调查清单事项，不代表 30 条法律结论。

## 6. 产品差异化

1. **职责分离**：业务确认事实与补件，法务负责法律研究和结论；同一产品按角色提供不同界面。
2. **固定分母**：Pack 固定调查分母不会因 Scope 选择而消失，未覆盖项仍被显式保留。
3. **可拒绝**：事实或证据不足时，Gate 显示拒绝或受限状态，不猜测缺失内容。
4. **可复核**：ResearchItem、Claim 与 CoverageProof 分层呈现；法律内容标记为 `provisional`。
5. **可追溯**：正式结果来自真实 API，材料、事实、版本、状态与审计事件可关联核验。
6. **外部边界清楚**：工程验证不能替代律师认证、客户 UAT、客户生产部署或正式 Release；上述状态保持 `blocked_external`。

## 7. 已知问题与使用边界

- 当前仅对首个 Capability Pack 完成端到端验证；环境许可研究较深，其他维度仍为初步协查。
- 未声称完整覆盖拉美、全巴西或市级规则，也未声称实时完整更新。
- Aurora 是虚构测试案例，不包含真实企业或客户数据，不构成正式法律意见。
- 本地比赛启动会重建隔离比赛数据；不要将固定测试账号用于任何生产环境。
- 若 `8010` 或 `5180` 被占用，启动脚本会拒绝复用未知服务；释放端口后重新启动。
- `blocked_external` 表示缺少真实外部证据，是预期安全边界，不是系统失败。
