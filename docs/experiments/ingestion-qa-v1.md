# 实验④审计记录：官方法规 PDF 摄取锚点遗漏率 v1/v2

## 预注册设计

在运行解析前，v1 冻结了 10 份与圣保罗州环境许可直接相关的 AL-SP 官方法规文本和每份 3 个可人工核对的锚点，共 30 个锚点。阈值预注册为：锚点遗漏率不高于 5% 时，只允许声称“本冻结样本中的 PDF 摄取锚点具有相对一致性”；超过 5% 时，必须逐份对照原文，且不得作一致性声明。下载、渲染或解析发生任何错误都会阻断结论，不能按“未命中”稀释分母。

样本包含 AL-SP 页面直接提供的 1 份原生官方 PDF，以及 9 份由固定 Playwright Chromium 将官方 HTML 正文打印得到的实验 PDF。后者不是 AL-SP 发布的原生 PDF，因此在目标清单和逐条结果中始终标为 `official_html_rendered_pdf`，不与原生来源混称。

## 指标边界

这里测量的是 `manually_annotated_anchor_omission_rate`：平台现有安全校验和 PDF 文本解析之后，30 个预先登记的标题、条款或主题短语有多少未能在归一化文本中找到。归一化只折叠大小写、重音符、标点和空白。

它**不是**逐字符错误率、OCR 精度、全文完整率、修法沿革完整率或法律正确率。9 份 HTML 打印 PDF 主要用于验证相同官方正文经过 PDF 容器后是否仍能被平台读取；扫描件 OCR、复杂表格和电子签章均不在范围内。

## 作废结论

v1 初步显示 `25/30`、遗漏率 16.67%，但随后的源文本复核证明全部 5 个未命中锚点在 PDF 渲染前就不在官方 HTML 中：4 个标题使用了错误的编号符号形式，另 1 个短语有拼写差异。因此 v1 被作废，不产生摄取结论。v2 增加“源锚点必须先存在”的阻断门，但又发现 3 个标题日期遗漏官方原文中的前导零，故同样在测量前作废。

保留这两轮失败是实验纪律的一部分；它们没有被删除、重写为通过或计入 v3 结果。有效结论仅见 [v3](./ingestion-qa-v3.md)。
