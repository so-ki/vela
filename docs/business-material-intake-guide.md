# 协查材料说明 · 业务端 & 法务端

---

## 给业务同事

### 您需要做什么？

上传项目方案文件（支持 Word、PDF、文本，可多个文件），核对抽取的客观事实，并确认您已知晓当前完整支持边界。

您**不需要**事先决定「该填哪些字段」——需要哪些信息、是否够用，由法务在协查过程中按合规维度判断。

您的责任是：**确认方案中的项目事实真实、完整**（对应发改委/商务部项目材料中的业务侧信息），不是判断法律结论。

当前唯一正式 Capability Pack 是 `brazil_new_energy_greenfield`，即 **巴西 · 新能源制造 · 绿地设厂**。业务知情确认不代表业务判断其法律适用性；最终范围由法务确认。

### 推荐流程

```
选择方案文件（可多个）→ 上传完成 → 进入材料核对页
    → 核对/修改客观事实 → 查看当前 Capability Pack 卡片
    → 勾选支持边界知情确认 → 提交 → pending_scope
```

### 核对表里有什么？（对齐实务）

| 分组 | 字段 | 业务是否要确认 |
|------|------|----------------|
| **项目信息** | 项目名称*、投资目的地、投资结构*、资金来源、主要内容 | **是** |
| **业务描述与风险** | 业务描述*、已知风险 | **是** |
| **关键时间线** | 董事会/开工/投产 | 有则填 |

\* = 提交前必填

### 原文件会怎样？

您上传的**原始方案文件会一并归档**，法务可随时下载回看，不仅用于 AI 抽取。

提交只会创建 `pending_scope`、`scenario_scope.proposed` 与适配结论；在法务确认并冻结 snapshot 前，不会生成清单、RAG 或简报。

### 法务退回后

按驳回意见在**材料核对页**里改字段即可重新提交；一般**不必重新上传**，除非法务另行要求。

---

## 给法务同事

查看后端提出的 Capability Pack、适配结论、材料缺口和业务事实；选择法律维度与必要议题后，点击 **「确认范围并生成」**。系统原子冻结 Capability Pack、规则、语料与 generation config，再启动唯一 generation attempt。

---

## 一句话总结

- **业务**：上传方案 → 确认**项目事实** → 查看支持边界并知情确认
- **法务**：核对 proposed scope → 定维度与议题 → 确认范围并生成
- **系统**：先创建 `pending_scope`，法务确认后冻结 snapshot，再生成并持久化清单、RAG 与简报
