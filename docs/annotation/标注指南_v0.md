# 标注指南 v0（骨架 · 待填充）

> 状态：v0 骨架。四节结构已定，内容随首批 10 张规则卡与 3 案金标准试点逐步填充。
> 变更规则：本指南的每次修改必须记录在文末"变更记录"，并注明触发它的具体案例或争议。

## 1. 术语表（Glossário）

| 中文 | 葡语 | 英语 | 定义（本项目内） |

| 红旗 | alerta vermelho | red flag | 待填 |

## 2. 标注对象（O que se anota）

- **规则卡核验**：每张卡输出四个判定之一：`确认无误 / 引用有误 / 要件拆分有误 / 遗漏例外或修订`，附一句理由与依据（条款号或官方链接）。
- **案例标注**：给定模拟场景（中文＋葡语摘要），标注：
  1. 触发的规则卡 ID 列表；
  2. 每条触发的置信度（确定/倾向/存疑）；
  3. 该场景下**不应**触发但容易误触发的规则卡（负样本，同等重要）。
- （待填：材料块级标注、抽取事实核对）

## 3. 判定标准（Critérios）

- 待填：什么算"引用有误"（错条款号 vs 错法源 vs 已废止）。
- 待填："存疑"的使用门槛——鼓励标注存疑而非猜测；**"不知道"是合法且受鼓励的答案**。
- 待填：修订链判定——以 LexML legislationChanges / Planalto 整合文本为准的核对顺序。

## 4. 争议仲裁（Arbitragem）

- 待填：标注者之间不一致时的处理流程（双标→讨论→第三人裁决→记录分歧原因）。
- 待填：中方团队与巴西标注者对法律理解冲突时，以葡语原文与官方来源为最终依据；无法消解的分歧保留双方意见并标注 `disputed`。
- 所有仲裁结果回写进第 1/3 节，成为指南的一部分。
